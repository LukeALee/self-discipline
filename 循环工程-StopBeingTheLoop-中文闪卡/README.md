## ✍️ 小红书发布建议

**标题(参考):**
1. **别再当那个「循环」了!让 Claude 在你睡觉时干活**
2. **做出 Claude Code 的人,已经不写 prompt 了**
3. **/goal 和 /loop:让 AI 自己干到「完成」**

**正文文案(参考):**

> 做出 Claude Code 的人 Boris Cherny 说:「我不再给 Claude 写 prompt 了。」🤯
> 他改写「循环」——一个会**自检、自记、自停**的小系统,替你一遍遍驱动 AI,直到事情做完。
>
> 这套思路就两个命令👇
> ⚽ `/goal`:有终点线,干到「完成」为止,每轮自动自检;
> 🔁 `/loop`:没终点只有节拍,盯着某件事反复跑。
>
> 关键不是「写更长的 prompt」,而是给它一份**章程**:目标 / 活在哪 / 怎么干 / 怎么自检 / 怎么记(LOOP-STATE.md)/ 何时停。
> 挑一件你总在手动做的碎活,今晚就让它替你跑~ 第一次睡醒发现活干完了,你就回不去了。
>
> 概要据 @Raytar 原文整理,内容以原文为准。
